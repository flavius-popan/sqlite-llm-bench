Skill Tiers?
Tiered packs (each pack runs in minutes; users can chain packs):
L0 Smoke: single-table selects, filters, simple aggregations, ORDER BY, LIMIT.
L1 Joins: inner/left joins, key/foreign-key reasoning, aliasing.
L2 Grouping: GROUP BY, HAVING, multi-agg, nested filters.
L3 Subqueries/EXISTS: IN/EXISTS, scalar subqueries, correlated filters.
L4 CTEs & Window: CTE chains; window functions subset supported by SQLite.
L5 Traps: NULL semantics, LIKE/collation quirks, date/time parsing, type affinity, string vs numeric comparisons, reserved keywords in identifiers.
Lx Robustness (optional): paraphrases, column reorderings, name obfuscations (Dr.Spider-style).
